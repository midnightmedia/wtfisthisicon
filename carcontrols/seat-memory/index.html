Car buttons

Seat memory buttons (M, 1, 2, 3)

Also called: memory seat, seat memory, driver profile buttons, SET button, memory buttons

WTF it means

These save your driving position. The car remembers where the seat (and on many cars the door mirrors and steering wheel) were set, so two drivers can each get their own position back with one press.

What to do about it

Set everything how you like it, press M (or SET), then press 1, 2 or 3 within a few seconds to save. From then on, pressing that number brings it all back. Some cars link a memory to each key, so it adjusts as you unlock.

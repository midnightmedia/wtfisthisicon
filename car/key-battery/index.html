Key fob battery low

Also called: key battery low, remote key battery, smart key battery, replace key battery

Relax, it's fine

WTF it means

The battery in your remote key is running out. The remote locking range gets shorter first, then keyless entry and start get unreliable.

What to do about it

Replace the battery soon. It's usually a coin cell (often a CR2032, but check the old one) behind a small panel or a hidden release button. If it dies completely, most cars have a backup: a hidden key blade for the door, and a spot on the steering column or start button where you hold the key to start the car.

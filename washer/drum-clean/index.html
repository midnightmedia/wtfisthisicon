Washing machine

Drum clean / tub clean

Also called: tub clean, drum clean, self clean, machine care, hygiene clean

WTF it means

A hot cleaning cycle for the empty machine, to remove limescale, detergent residue, mould and smells. Many machines light it up as a reminder every few dozen washes.

What to do about it

Run it with the drum empty (yes, no laundry at all), optionally with a washing-machine cleaner. Afterwards, wipe the rubber door seal and leave the door ajar.

For the record

A smelly machine usually means too many cool washes. Leaving the door and detergent drawer open between washes helps a lot.

Washing machine

Child lock

Also called: child safety lock, key lock, button lock, control lock

WTF it means

The buttons are locked so little fingers (or cats) can't change or stop the programme.

What to do about it

To unlock, press and hold the button (or pair of buttons) marked with the lock symbol for about 3 seconds. The panel or manual shows which.

For the record

If none of the buttons respond, check this first. Some brands use a key symbol instead.

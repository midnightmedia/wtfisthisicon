Keyboard symbols

Mission Control key (F3)

Also called: Mission Control, Exposé, F3, Spaces, show all windows, Task View

WTF it means

On a Mac this key (F3) opens Mission Control: all your open windows spread out so you can pick one, with your desktops (Spaces) along the top. A grand name for a simple, very handy trick.

What to do about it

Press it, then click the window you want. You can also swipe up with three or four fingers on the trackpad, or press Control + Up Arrow. The Windows version is Task View: Windows key + Tab.

For the record

On older Macs this key was called Exposé. Drag a window onto a desktop at the top of Mission Control to move it there.

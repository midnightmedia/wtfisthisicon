Keyboard symbols

Spotlight search key (magnifying glass)

Also called: Spotlight, search key, F4, Launchpad, Command Space

WTF it means

On newer Macs, the magnifying glass on F4 opens Spotlight: the search bar that finds apps, files and settings. It also does quick sums and unit conversions.

What to do about it

Press it (or Command + Space on any Mac), type a few letters of what you want and press Return. On Windows, press the Windows key and start typing, or use Windows key + S.

For the record

Older Macs had Launchpad on F4 instead: a grid of little squares that shows all your apps. On many Chromebooks, a magnifying-glass key on the left opens search.

Keyboard symbols

Menu key (right-click key)

Also called: Menu key, Application key, App key, context menu key, right-click key, ≣

WTF it means

Opens the right-click menu (context menu) for whatever is selected or wherever the cursor is, just as if you'd clicked the right mouse button. The key nobody notices until the mouse dies.

What to do about it

Handy when your mouse or touchpad won't right-click. No menu key? Shift + F10 does the same on Windows. On a Mac, hold Control and click.

For the record

It usually sits between the right-hand Alt and Ctrl keys. Many laptops have dropped it, and some newer Windows laptops have a Copilot key in that corner instead.

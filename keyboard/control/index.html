Keyboard symbols

Control key (^)

Also called: ⌃, Ctrl, Control, Ctl, ^, caret, Strg

WTF it means

The ^ means Control (Ctrl). On Windows and Linux, Ctrl is the main shortcut key (Ctrl + C copies). On a Mac, Command does most of the shortcuts and Control is the helper. Mac menus show it as ^.

What to do about it

On a Mac, hold Control and click to get the right-click menu. Control + Command + Q locks the screen. If instructions say ^C, that means hold Ctrl and press C.

For the record

Strg on German keyboards is short for Steuerung, which means control. Same key, no vowels.

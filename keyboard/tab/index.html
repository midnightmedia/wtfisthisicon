Keyboard symbols

Tab key

Also called: ⇥, ↹, ⇤, Tab, tabulator, tab key

WTF it means

Tab jumps forward: to the next box in a form, the next button, or the next indent stop in a document. The arrow running into a bar shows it jumping along to the next stop.

What to do about it

Shift + Tab goes back one box. Alt + Tab (Windows) or Command + Tab (Mac) switches between open apps. In a bulleted list, Tab indents an item and Shift + Tab moves it back out.

For the record

Many PC keyboards print two arrows going opposite ways, as if the key can't make up its mind. The one pointing left to a bar is for Shift + Tab, and the one pointing right to a bar is for Tab. Macs and menus usually show just the right-pointing one. The name comes from the typewriter's tabulator, used to line up columns.

Command key (Cmd)

Also called: ⌘, Cmd, Command, Apple key, clover key, splat, Bowen knot, place of interest sign

WTF it means

The Mac's main shortcut key, doing the job Ctrl does on Windows. Hold it and tap a letter: Command + C copies, Command + V pastes, Command + Z undoes and Command + Q quits the app.

What to do about it

Windows instructions say Ctrl? On a Mac, try Command. Handy ones: Command + Space opens Spotlight search, Command + Tab switches apps, and Command + Shift + 4 lets you drag a box to take a screenshot.

For the record

Steve Jobs didn't want the Apple logo all over the menus, so designer Susan Kare picked this loop symbol from a book of symbols. In Nordic countries it marks places of interest on signs and maps, where it isn't asking you to copy anything. Older Mac keyboards had an Apple logo on the key too, which is why people still call it the Apple key.

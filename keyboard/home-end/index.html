Keyboard symbols

Home and End keys

Also called: Home, End, ↖, ↘, ⇱, ⇲, Pos1, Ende

WTF it means

Home jumps the cursor to the start of the line and End jumps to the end of it. Some keyboards print them as diagonal arrows pointing into a corner, which is cryptic even by keyboard standards. Mac menus show them as up-left and down-right arrows.

What to do about it

Ctrl + Home and Ctrl + End go to the very top or bottom of a document or spreadsheet. On a Mac, use Command + Left / Right Arrow for the start or end of a line, and Command + Up / Down Arrow for the top or bottom of the document.

For the record

Mac laptops have no Home or End keys. Fn + Left Arrow and Fn + Right Arrow stand in for them, but in most Mac apps they scroll to the top or bottom rather than moving the cursor.

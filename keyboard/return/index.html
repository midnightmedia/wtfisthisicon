Keyboard symbols

Return / Enter key

Also called: ⏎, ↩, ↵, Return, Enter, carriage return, new line

WTF it means

Return or Enter: start a new line when typing, or confirm, send or OK whatever you're doing. The bent arrow is an old typewriter going down a line and back to the left margin.

What to do about it

In chat apps (WhatsApp on a computer, Teams, Slack), Enter sends the message, finished or not. Press Shift + Enter for a new line instead. In Mac menus, a hooked arrow next to a command means the Return key.

For the record

Full-size keyboards have a second Enter key on the number pad. Macs call that one Enter and show it in some menus as a small arrowhead between two lines. A few apps treat it differently from Return.

Keyboard symbols

Delete / Backspace key

Also called: ⌫, Backspace, Delete, BkSp, back space, erase left

WTF it means

Deletes the character to the left of the cursor. On a Mac the key says "delete" and works like Backspace on Windows. Windows keyboards often just print a long arrow pointing left.

What to do about it

To delete to the right instead, press Fn + Delete on a Mac laptop. Option + Delete (Ctrl + Backspace on Windows) removes a whole word. In Finder, Command + Delete moves the selected file to the Trash (Bin).

For the record

In Mac menus, this symbol next to a command means the Delete key.

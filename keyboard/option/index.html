Keyboard symbols

Option / Alt key

Also called: ⌥, Option, Opt, Alt, alt key, alternate

WTF it means

Option is the Mac's version of the Windows Alt key, and many Mac keyboards print "alt" on it too. It unlocks the alternative version of things: hidden menu items, extra settings and special characters.

What to do about it

Hold Option while a menu is open to reveal hidden commands, or while typing to get symbols: Option + G gives ©, Option + 8 gives •. Option + Command + Esc opens Force Quit for a frozen app. Using a Windows keyboard on a Mac? Its Alt key works as Option.

For the record

The symbol is usually explained as a railway switch: one track runs straight on and the other branches off. An alternative route, just like the key. Obvious, once someone tells you.

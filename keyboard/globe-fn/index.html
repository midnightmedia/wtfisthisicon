Keyboard symbols

Fn / Globe key

Also called: fn, Fn, function key, globe key, 🌐, Fn Lock, FnLock, world key

WTF it means

Fn (function) switches keys to their second job. That's mainly the top row, which can be either F1–F12 or brightness, volume and media controls. On newer Macs and iPad keyboards it also has a globe, used for emoji and keyboard languages.

What to do about it

Pressing F5 and getting volume or brightness instead, or the other way round? Hold Fn while you press it. On a Mac, tapping the globe key on its own opens the emoji picker or switches language, depending on System Settings › Keyboard. Fn + F switches full screen on or off.

For the record

On Windows laptops, Fn Lock (often Fn + Esc, sometimes marked with a padlock and "Fn") swaps the top row's default so you don't have to hold Fn every time. On a Mac the same choice is in System Settings › Keyboard › Keyboard Shortcuts › Function Keys.

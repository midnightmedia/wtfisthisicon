Keyboard symbols

Windows key

Also called: Win key, Windows logo key, Start key, Super key, Meta key, WinKey, ⊞

WTF it means

The Windows key opens the Start menu, and it's the starting point for lots of handy shortcuts. On Linux it's called the Super key, which sounds like a promotion. Plug a Windows keyboard into a Mac and it works as Command.

What to do about it

Useful combos: Windows + D shows the desktop, Windows + L locks the PC (do it when you walk away), Windows + E opens File Explorer, Windows + Shift + S takes a screenshot of part of the screen, Windows + V shows clipboard history and Windows + . (full stop) opens emoji.

For the record

The logo has changed over the years: a wavy four-colour flag (Windows 95 to 7), a slanted window (8 and 10) and four flat squares (11). Gaming keyboards often have a mode that disables it, so a stray press doesn't throw you out of a game.

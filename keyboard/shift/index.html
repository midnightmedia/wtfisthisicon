Keyboard symbols

Shift key

Also called: ⇧, Shift, shift arrow, upper case

WTF it means

Shift: hold it while typing a letter to get a capital, or a number key to get the symbol printed above it (Shift + 1 = !). In shortcuts it adds a twist to the plain version: Command + Z undoes, Command + Shift + Z redoes.

What to do about it

Screenshots: on a Mac, Command + Shift + 3 takes the whole screen and Command + Shift + 4 lets you drag a box. On Windows, it's Windows key + Shift + S. Hold Shift while clicking to select everything between two items in a list.

For the record

Pressed Shift five times on Windows and got a pop-up about Sticky Keys? That's an accessibility feature. Click No to dismiss it, or switch the shortcut off in Settings › Accessibility › Keyboard.

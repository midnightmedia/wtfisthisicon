Keyboard symbols

Eject key

Also called: ⏏, eject, media eject, disc eject, eject key

WTF it means

On older Mac keyboards, the top-right key opens the CD/DVD drive. In Finder and in menus, the same symbol means safely disconnect a drive or memory stick.

What to do about it

Before unplugging a USB stick or external drive from a Mac, click the eject symbol next to it in the Finder sidebar (or select it and press Command + E), so nothing gets corrupted. On older Macs, Control + Eject brings up the restart / sleep / shut down box.

For the record

Newer Mac keyboards don't have this key. Macs lost their disc drives years ago, so there was nothing left to eject. The top-right key is now the power / Touch ID button.

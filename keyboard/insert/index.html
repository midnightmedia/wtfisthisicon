Insert key (Ins)

Also called: Insert, Ins, overtype, overwrite mode, Einfg

WTF it means

Insert switches between normal typing and overtype mode, where everything you type eats the letters to the right of the cursor instead of pushing them along. Switch it on by accident and you get a classic "why is my text disappearing?" moment.

What to do about it

If new typing is overwriting your words, press Insert once to switch back. In Word you can stop it happening: File › Options › Advanced, then untick "Use the Insert key to control overtype mode".

For the record

Old-school shortcuts still work in most Windows apps: Ctrl + Insert copies and Shift + Insert pastes. Macs don't have an Insert key.

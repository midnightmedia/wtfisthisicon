Keyboard symbols

The squiggles printed on your keys. 25 of them, decoded.

Command key (Cmd)

The Mac's main shortcut key, doing the job Ctrl does on Windows.

Option / Alt key

Option is the Mac's version of the Windows Alt key, and many Mac keyboards print "alt" on it too.

Control key (^)

The ^ means Control (Ctrl).

Shift key

Shift: hold it while typing a letter to get a capital, or a number key to get the symbol printed above it (Shift + 1 = !).

Caps Lock

Caps Lock makes every letter you type a CAPITAL until you press it again, which is how perfectly calm emails end up sounding like shouting.

Delete / Backspace key

Deletes the character to the left of the cursor.

Forward delete (Del)

Deletes the character to the right of the cursor, the opposite of Backspace.

Return / Enter key

Return or Enter: start a new line when typing, or confirm, send or OK whatever you're doing.

Tab key

Tab jumps forward: to the next box in a form, the next button, or the next indent stop in a document.

Escape key (Esc)

Escape: cancel, close or back out of whatever just popped up, such as a dialog box, a menu, a full-screen video or a half-finished selection.

Eject key

On older Mac keyboards, the top-right key opens the CD/DVD drive.

Fn / Globe key

Fn (function) switches keys to their second job.

Mission Control key (F3)

On a Mac this key (F3) opens Mission Control: all your open windows spread out so you can pick one, with your desktops (Spaces) along the top.

Spotlight search key (magnifying glass)

On newer Macs, the magnifying glass on F4 opens Spotlight: the search bar that finds apps, files and settings.

Dictation key (microphone)

On newer Macs (F5), the microphone starts Dictation: speak, and your words get typed wherever the cursor is.

Do Not Disturb / Sleep key (moon)

On newer Mac keyboards, the moon on F6 switches Do Not Disturb on or off, so notifications stay quiet.

Windows key

The Windows key opens the Start menu, and it's the starting point for lots of handy shortcuts.

Menu key (right-click key)

Opens the right-click menu (context menu) for whatever is selected or wherever the cursor is, just as if you'd clicked the right mouse button.

Print Screen (PrtSc)

Takes a screenshot.

Scroll Lock (ScrLk)

A key from the early days of the PC that refuses to retire.

Pause / Break

Another relic from early PCs.

Insert key (Ins)

Insert switches between normal typing and overtype mode, where everything you type eats the letters to the right of the cursor instead of pushing them along.

Home and End keys

Home jumps the cursor to the start of the line and End jumps to the end of it.

Page Up and Page Down

Page Up and Page Down scroll up or down one screenful at a time, which beats a lot of frantic scrolling.

Num Lock (padlock with a 1)

Num Lock switches the number pad between typing numbers (light on) and working as arrow and navigation keys, using the little Home, End and arrow labels under the numbers (light off).

Keyboard symbols

Pause / Break

Also called: Pause, Break, Pause Break, Pause/Break, Ctrl + Break, Pause key

WTF it means

Another relic from early PCs. Pause freezes some text-only screens (like start-up messages) so you can read them, and Ctrl + Break stops a running command-line program or an old-style macro.

What to do about it

You'll rarely need it. One useful trick: Windows + Pause opens your PC's system info (Settings › System › About), showing the processor, memory and Windows version.

For the record

Pressing it by accident does no harm, unlike a stray press of Insert. Some games still use it to pause, and on laptops it's often hidden behind Fn or missing entirely.

Keyboard symbols

Page Up and Page Down

Also called: PgUp, PgDn, Page Up, Page Down, ⇞, ⇟, Bild auf, Bild ab

WTF it means

Page Up and Page Down scroll up or down one screenful at a time. Some keyboards and Mac menus show them as arrows with two lines across the stem.

What to do about it

On a Mac laptop, press Fn + Up Arrow or Fn + Down Arrow. Ctrl + Page Up / Page Down switches between browser tabs, and between sheets in Excel.

For the record

In a web browser, the Space bar does the same as Page Down, and Shift + Space goes back up.

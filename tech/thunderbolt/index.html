Phones & gadgets

Thunderbolt

Also called: Thunderbolt 3, Thunderbolt 4, Thunderbolt 5, TB3, TB4, Intel Thunderbolt

WTF it means

This port supports Thunderbolt, a super-fast connection for docks, multiple monitors, fast external drives and graphics boxes. Since Thunderbolt 3 it uses the USB-C shape, so it also works as a normal USB-C port. Same hole, more talent.

What to do about it

Plug docks, high-end monitors and fast drives in here for the best results. Use a Thunderbolt cable (it has the same bolt logo) to get full speed.

For the record

A plain lightning bolt without the arrowhead next to a port usually means charging, not Thunderbolt, so that little arrowhead is doing a lot of work. On Macs from about 2011–2015, Thunderbolt used the smaller, square Mini DisplayPort shape.
